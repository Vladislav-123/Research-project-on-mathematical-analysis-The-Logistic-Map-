# Исследовательская работа: Logistic map

**Дисциплина:** Математический анализ и основы вычислений  
**Автор:** Чепелкин Владислав Андреевич   
**Год:** 2026

## О работе

Работа посвящена исследованию одномерных дискретных динамических систем на примере логистического отображения и его модификации для индивидуального варианта.

Выполнены:
- доказательство сохранения интервала (0,1);
- анализ влияния параметра r на вид отображения;
- поиск неподвижных точек и исследование их устойчивости;
- доказательство монотонности и сходимости последовательностей;
- построение лестницы Ламерея;
- численное исследование циклов и каскада удвоения периода;
- сравнение логистического отображения и отображения варианта.
